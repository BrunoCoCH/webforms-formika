Webforms setup

Configure allowed websites for your contact worker, copy SITE_CONFIG for Cloudflare, and paste form snippets into Webflow or any site. Nothing is sent to a server — data stays in this browser (localStorage). On GitHub Pages, saved data is tied to this origin (example.github.io).
